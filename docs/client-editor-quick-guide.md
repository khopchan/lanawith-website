# LANA WITH. 発注者向け・かんたん編集ガイド

このガイドは、IT初心者の編集担当者が、画像変更・文章変更をCodexへ依頼し、管理責任者の承認を受けて安全に公開するためのものです。

## 編集担当者が行うこと

編集担当者が行う操作は、原則として次の4つだけです。

1. 変更したい画像または文章を準備する
2. Codexへ日本語で依頼する
3. 完成したVercel Previewを確認する
4. 管理責任者へ公開承認を依頼する

コード、Gitコマンド、DNS、環境変数を操作する必要はありません。

---

# 画像を変更したいとき

## 1. 画像を準備する

Google Photosから使用したい画像を選び、端末へ保存します。

## 2. Codexへ画像を添付する

LANA WITH.のリポジトリを対象にしたCodexの作業画面を開き、画像を添付して次の文章を送ります。

```text
【LANA WITH. 商品画像変更依頼】

添付した画像を、LANA WITH.公式ホームページの商品画像として使用してください。

【変更対象商品】
・［正式な商品名］

【同じ画像を使用する商品】
・［必要な場合のみ記載］

【変更内容】
現在の商品画像を、今回添付した画像へ変更してください。

【公開用ファイル名】
［例：matcha-granola-new.jpg］

【希望する見え方】
・商品が中央に分かりやすく表示される
・パソコンとスマートフォンの両方で見切れない
・必要な場合だけ表示位置を調整する

【変更してよい範囲】
・指定商品の画像
・指定商品の画像参照
・対象画像だけの表示位置

【変更してはいけない範囲】
・商品名
・価格
・商品説明
・容量
・アレルギー情報
・賞味期限
・保存方法
・他の商品画像
・商品表示順
・ページ全体のデザイン
・ボタンとリンク

作業用ブランチを作成し、Pull RequestとVercel Previewを作成してください。
管理責任者が承認するまでmainへマージしないでください。
```

## 3. Codexから確認質問が来た場合

不明点がある場合、Codexは作業を止めて質問します。

例：

- 通常サイズとミニサイズの両方を変更しますか
- 複数画像のうち、どれを使用しますか
- 画像ファイル名はこの名前でよいですか

質問に回答した後、作業を続けてもらいます。

## 4. Previewを確認する

CodexからVercel Preview URLが届いたら開きます。

確認項目：

- 指定した画像へ変わっている
- 商品名が正しい
- 価格が変わっていない
- 他の商品画像が変わっていない
- パソコンで正常に見える
- スマートフォンで正常に見える
- 画像が不自然に切れていない

問題がある場合は、同じCodexの作業画面で修正内容を伝えます。

```text
Vercel Previewを確認しました。

【修正対象】
［商品名］の商品画像

【現在の問題】
［例：商品が上側で切れています］

【修正希望】
［例：画像を少し下へ移動し、商品全体が見えるようにしてください］

他の商品、商品名、価格、文章、ページ全体のレイアウトは変更しないでください。
同じ作業用ブランチで修正し、Previewを更新してください。
```

# 管理責任者へ公開を依頼するとき

Previewに問題がないことを確認後、管理責任者へ次の内容を送ります。

```text
LANA WITH.の変更Previewを確認しました。

【変更対象】
［商品名または対象箇所］

【変更内容】
［画像変更／文章変更／価格変更］

【Preview URL】
［URL］

内容に問題ありません。
Pull Requestの最終確認と本番公開をお願いします。
```

管理責任者がPull Requestを確認・承認し、`main`へマージします。

# 編集担当者が触らないもの

次の項目は管理責任者または制作管理者だけが扱います。

- `main`へのマージ
- GitHubの管理設定
- VercelのDomains
- Vercelの環境変数
- XServer Domain
- DNSとネームサーバー
- APIキー
- リポジトリの公開・非公開設定

# 困ったとき

## 画像が添付できない

画像を端末へ保存し直し、JPG、PNG、WEBPのいずれかで再度添付します。

## 変更箇所が分からない

画面のスクリーンショットを添付し、赤丸や文章で場所を説明します。

## Codexが質問している

推測で回答せず、商品名、価格、対象範囲を確認してから回答します。

## Previewに問題がある

本番公開を依頼せず、同じ作業画面で修正依頼を送ります。

## 間違えて公開された可能性がある

追加の変更を行わず、管理責任者へすぐ連絡します。
